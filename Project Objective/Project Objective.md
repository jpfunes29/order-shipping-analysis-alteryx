# End-to-End Data Workflow Project

## Objective
The objective of this project was to build an end-to-end data workflow that improved the accuracy and usability of order and product data. Using **Alteryx**, I developed a streamlined process that connected multiple datasets, standardized key fields, and applied business logic to surface high-risk orders for review.

## Workflow Details

1. **Order Mapping**
   - Mapped each order to the correct shipping method based on its assigned priority.
   - Ensured consistent logistics classification across the dataset.

2. **Product Data Integration**
   - Integrated product category information with SKU-level product details.
   - Created a unified product reference table to enable deeper product-level analysis.

3. **Data Enrichment & Exception Handling**
   - Merged enriched product data with the order stream.
   - Identified Technology items shipped via Freight and flagged them with a **"REVIEW"** indicator.
   - Allowed teams to quickly isolate exceptions and improve operational oversight.
